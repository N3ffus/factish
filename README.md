# Factish

Игра «найди настоящий факт» по макету `factish_v5.html`. Игровые утверждения берутся только из CSV-файлов, перечисленных в `CONTENT_FILES` (`backend/import_content.py`): сейчас это `content/factish_100_facts_and_fakes.csv`, `content/factish_new_part01.csv` и `content/factish_new_part02.csv`, вместе 450 фактов и 450 фейков. Факты и фейки хранятся в разных таблицах SQLite. Новые файлы добавляются в конец списка, а не заменяют прежние. Каждый раунд независимо выбирает по одной случайной записи из каждой таблицы; сложность, сфера и пояснение сохраняются вместе с записью.

## Локальный запуск

Нужны Python 3.12+ с [uv](https://docs.astral.sh/uv/) и Node.js 20.19+.

```powershell
uv sync --group dev
uv run alembic upgrade head
uv run python -m backend.import_content
uv run uvicorn backend.app:app --reload --host 127.0.0.1 --port 8000
```

В другом терминале:

```powershell
cd frontend
npm ci
npm run dev
```

Открыть `http://127.0.0.1:5173`. API доступно через Vite proxy. Для запуска собранного сайта из FastAPI выполните `npm run build` в `frontend` **до** запуска Uvicorn и откройте `http://127.0.0.1:8000`.

## Настройка

- `FACTISH_SECRET_KEY`: случайный секрет для подписи JWT. Перед публикацией обязательно задать новый секрет.
- `FACTISH_SECURE_COOKIES=1`: отправлять cookie только по HTTPS; включить при публикации.
- `FACTISH_FRONTEND_ORIGIN`: разрешённый адрес клиента, если он отличается от адреса локальной разработки.
- `FACTISH_DATABASE_URL`: адрес SQLite, по умолчанию `data/factish.sqlite3`.
- `FACTISH_COOKIE_PATH`: путь cookie при размещении сайта в подпапке; для OpenClaw — `/factish`.

Пароли хранятся в виде хешей Argon2id. JWT находятся в HttpOnly-cookie: доступ на 15 минут, обновление на 30 дней; у гостей отдельный подписанный идентификатор на 180 дней. Сервер не хранит сессии в памяти. Выход удаляет cookie в браузере; ранее выданный JWT технически действителен до истечения срока или смены секрета.

Гостевая статистика зеркалируется в `localStorage`, а проверенные сервером игровые записи остаются в SQLite. При регистрации или входе записи с гостевым идентификатором привязываются к аккаунту. Для переноса в рейтинг необходимо сохранить гостевую cookie: локальную копию без неё сервер не может подтвердить.

Рейтинг считает лучший стрик среди игр, начатых за выбранный период. Среднее считается по завершённым играм, включая игры с нулевым результатом. «Сегодня» начинается в 00:00 по Москве. Гостевые игры попадают в общий рейтинг только после привязки к аккаунту.

## Проверка

```powershell
uv run pytest -q
cd frontend
npm run build
```

Импорт CSV можно повторять: записи сопоставляются по тексту утверждения (номера `id` в разных файлах могут пересекаться, поэтому файл и `id` хранятся только как происхождение записи). Утверждение, которое встречается в двух файлах, останавливает импорт. Записи, которых больше нет ни в одном файле из списка, становятся неактивными. Миграции выполняются командой `uv run alembic upgrade head`.

## OpenClaw

Публичный адрес: `https://neffus.ru/factish/`. Caddy направляет только `/factish/*` в контейнер на локальном порту `18081`; остальной `neffus.ru` продолжает работать по прежнему маршруту.

Перед отправкой новой версии соберите клиент с префиксом `/factish/`:

```powershell
cd frontend
$env:FACTISH_BASE_PATH='/factish/'
npm run build
```

На сервере приложение расположено в `/home/clawadmin/apps/factish`. `docker compose -f compose.prod.yml up -d --build` запускает миграции и повторяемый импорт всех фактов и фейков. Данные SQLite и загруженные аватары находятся в постоянном каталоге `data/`; секрет JWT и HTTPS-настройки — в серверном `.env`.
