# Factish

Игра «найди настоящий факт»: в каждом раунде два утверждения, одно правдивое, другое выдуманное. Нужно угадать факт и продержать стрик как можно дольше.

**Играть:** https://neffus.ru/factish/

Бэкенд: FastAPI, SQLAlchemy, Alembic, SQLite. Фронтенд: TypeScript и Vite.

## Локальный запуск

Нужны Python 3.12+ с [uv](https://docs.astral.sh/uv/) и Node.js 20.19+.

```powershell
uv sync --group dev
uv run alembic upgrade head
uv run python -m backend.import_content
uv run uvicorn backend.app:app --reload --host 127.0.0.1 --port 8000
```

В другом терминале:

```powershell
cd frontend
npm ci
npm run dev
```

Откройте `http://127.0.0.1:5173`, API проксируется через Vite. Чтобы FastAPI отдавал собранный сайт, выполните `npm run build` в `frontend` до запуска Uvicorn и откройте `http://127.0.0.1:8000`.

## Настройка

- `FACTISH_SECRET_KEY` — секрет для подписи JWT; в продакшене обязателен.
- `FACTISH_SECURE_COOKIES=1` — отправлять cookie только по HTTPS.
- `FACTISH_FRONTEND_ORIGIN` — разрешённый адрес клиента, если он отличается от адреса локальной разработки.
- `FACTISH_DATABASE_URL` — адрес SQLite, по умолчанию `data/factish.sqlite3`.
- `FACTISH_COOKIE_PATH` — путь cookie, если сайт размещён в подпапке (например, `/factish`).
- `FACTISH_BASE_PATH` — префикс ассетов при сборке фронтенда для подпапки (например, `/factish/`).

## Контент

Утверждения берутся из CSV в `content/`, список файлов задан в `CONTENT_FILES` (`backend/import_content.py`). Факты и фейки хранятся в разных таблицах вместе со сферой, сложностью и пояснением. Каждый раунд независимо выбирает один случайный факт и один случайный фейк.

Импорт можно запускать повторно. Записи сопоставляются по тексту утверждения. Если одно утверждение встречается в двух файлах, импорт останавливается. Записи, которых больше нет ни в одном файле, становятся неактивными.

## Аккаунты и рейтинг

Пароли хранятся в виде хешей Argon2id. JWT лежат в HttpOnly-cookie: токен доступа живёт 15 минут, токен обновления — 30 дней. Гость получает подписанный идентификатор на 180 дней. При регистрации или входе гостевые игры привязываются к аккаунту.

Рейтинг учитывает лучший стрик среди игр, начатых за выбранный период, и средний результат завершённых игр. «Сегодня» начинается в 00:00 по Москве. Гостевые игры попадают в общий рейтинг только после привязки к аккаунту.


## Продакшен

Соберите фронтенд (в `frontend`) с нужным префиксом, например `$env:FACTISH_BASE_PATH='/factish/'; npm run build`. Затем запустите `docker compose -f compose.prod.yml up -d --build`. Секреты задаются в `.env` рядом с `compose.prod.yml`. При каждом старте контейнер применяет миграции и импортирует контент. База и загруженные аватары хранятся в каталоге `data/`.
